公网界面复查发现手机尚未加入语音时四列按钮过窄，将该状态也统一成两列。本地此时出现其他任务的编码和启动码率修改，当前主工作区两项测试失败：

- `media_dock_runtime_test.mjs`：开始共享选项新增 `codecMode`、`startBitrate`，与已有预期不符。
- `screen_share_reload_regression_test.mjs`：标准化选项新增上述字段，与已有预期不符。

这些编辑保留在原工作区，未纳入此次发布。最终候选从先前验证的 ZIP 提取，仅更新 `workspace-refinement.css`；独立候选的 231 项测试和实际浏览器 UI 检查通过后，按同一发布脚本打包并校验清单及 SHA256。线上仅原子替换该 CSS，无需再次重启；整个线上程序与最终候选包再次核对一致。

真实 `.env`、聊天记录及其他服务保留。Friend Footprints 的进程 PID 未变，未修改 Nginx、防火墙、服务器环境参数或数据存储路径。

## 公网验证

- 实际 Edge 浏览器：初始化期间不绘制旧布局、新界面加载完成、全部必要脚本和图标本地加载，无页面脚本错误和缺失资源；Socket.IO 使用 WebSocket；共享设置为顶层模态框，有开始/取消按钮；390px 手机视口控件完整。

- 部署结束检查：`voice-room` 与其他服务在线，SFU worker 监听 UDP 44444，无额外崩溃重启；配置哈希及切换时聊天记录哈希未变化。

测试使用合成媒体与本机 Edge，不能替代真实 FPS 游戏长时间观看、真实麦克风听感或微信真机实测。共享者和观看者需刷新页面、重新加入语音并重新开始共享。
