# 房间界面修整

## 已确认的问题与修复

| 问题 | 原因 | 修复 |
| --- | --- | --- |
| 首次显示旧三栏后跳成自由窗口 | 静态 DOM 先绘制，主模块随后移动 DOM | 完成布局恢复后显示；八秒超时/主模块失败给出重试 |
| 共享设置被其他窗口盖住或点穿 | 弹窗属于自由窗口的层叠上下文 | 原生顶层模态框；无原生 API 时使用页面级遮罩 |
| 选设置没有开始按钮 | 主按钮直接启动采集，设置仅悬停展开 | 先打开设置，明确取消/开始；开始点击保留浏览器用户激活 |
| 设备箭头第一次点击关闭菜单 | 鼠标进入先悬停展开，点击再次切换 | 将第一次点击作为确认展开，第二次点击才关闭 |
| 小窗口/手机按钮拥挤 | 旧手机版五列和隐藏共享按钮规则覆盖新布局 | 两列布局、可见文字和箭头、40px 手机按钮；窄窗口可滚动 |
| 首次进入依赖第三方加载 | PeerJS 和图标来自外部脚本 | 本地版本化脚本/CSS/字体，附许可证 |

## 保留的操作

自由拖拽、边缘拉伸、布局保存与恢复、折叠、隐藏和置顶都保留。只移动现有控件 DOM，不重建媒体组件。保存键和格式保持一致；现有布局优先。共享清晰度与媒体转发策略保持原约定。
