# 客户端首次打开黑屏修复

状态：本地源码已修复及验证，尚未重新打包、部署或更新用户安装版；客户端 package 仍为 0.1.4。此问题属于客户端本体，网页刷新不能修复已安装的旧启动逻辑。

## 原因

`main.cjs` 在创建 BrowserWindow 时使用 `show: true` 和旧深色 `#151923` 背景。网页标题栏由 preload 在 DOMContentLoaded 构造，CSS 又在 dom-ready 注入，所以公网页面还未返回时，已显示深色空窗口和孤立的原生 caption buttons。

## 修改

- `main.cjs` 初始窗口隐藏，背景与网站统一为 `#fbf7f9`。
- `window-startup.cjs` 等待实际网页、标题栏 CSS、正常/降级布局及两帧绘制后才允许显示；未创建另一套工具栏或加载遮罩。后续刷新仍为原窗口注入同一标题栏 CSS。
- 开始加载后最多等待 20 秒；离线、样式失败或首次绘制超时走现有本地无声错误界面。退出会取消等待，迟到的网络结果不能重新显示窗口。
- `window-lifecycle.cjs` 启动准备好之前阻止托盘或第二实例的 restore 提前显示空壳。
- `panels.cjs` 错误弹窗不绑定不可见主窗口，避免弹窗把未准备好的主窗口一起显示。
- `electron-builder.cjs` 显式包含新启动模块。未修改媒体、共享、频道或服务器。
