# 紧凑顶栏与更多操作（仅本地，2026-10-22）

## 改动

- 桌面网页顶部预留由 64px 收紧为 48px，内容区增加 16px。顶栏贴顶并加轻分隔线，去掉原本上下分散的空隙；品牌图标由 30px 收为 24px。
- 手机顶部预留由 64px 收紧为 56px，内容区增加 8px。频道 / 语音或共享 / 聊天三个入口保留，触摸按钮至少 44px 高。宽屏触摸设备也采用 56px 顶栏和 44px 点击目标。
- “复制诊断”和“下载客户端”收进各尺寸共用的“更多”，桌面顶栏常驻聊天入口和更多按钮。操作入口和原诊断复制逻辑保留。
- 关闭的更多操作组设为 inert，避免 Tab 进入隐藏操作；Esc / CloseWatcher 关闭时恢复菜单内的键盘焦点到更多按钮，点击外部关闭。旧 CloseWatcher 的迟到关闭不会关闭新打开的操作组。
- 原生客户端标题栏继续由 Windows overlay 决定高度，默认 40px。同步状态提示使用同一高度变量；窄/矮窗口下不把原生标题栏扩成网页高度。客户端下载项继续在客户端隐藏。
- 安全区仍参与顶部、左右间距计算；频道、聊天草稿和媒体节点不因开关更多操作而重建。

这些改动尚未提交、打包或部署。

### 回归

新增两项行为回归：宽屏更多操作的 inert 状态及媒体/草稿保持；CloseWatcher 焦点归还、旧关闭事件隔离及销毁释放。定向舞台布局测试 **20/20 通过**。

第一次完整测试 **771/772 通过**，唯一失败是原有安全区测试写死了旧的 64px 预留表达式；已改为检查顶栏高度变量加顶部安全区的合同。最终默认并发 `npm test` **772/772 通过**，定向 ESLint 和 `git diff --check` 通过。

自动化验证不替代真实手机安全区、触摸手感和用户视觉验收。
