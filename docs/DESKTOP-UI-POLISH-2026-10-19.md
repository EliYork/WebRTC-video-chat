# 客户端更新与确认界面整理

发布状态（2026-10-19 更新）：已随客户端 **0.1.4** 发布到生产更新源；网页构建 `904f5a67cec1caa42ebf8c05e0a0ffcb3599bd66`。未提交、打标签或 Push，没有覆盖用户安装的客户端。现有未提交性能修改及 `native/` 保留。完整记录见 [0.1.4 部署报告](DEPLOYMENT-2026-10-19-DESKTOP-014.md)。以下为实施过程与验证记录。

## 原因和实际修复

| 发现的问题 | 根本原因 | 本轮处理 |
| --- | --- | --- |
| 关于/更新多次弹系统消息框，风格不统一，可能伴随系统提示音 | `about.cjs`、`updater.cjs` 使用 Windows `showMessageBox` | 独立本地设置窗口，统一粉色视觉；日常流程不调用系统消息框、不播放操作音效 |
| 检查时像没有响应 | 仅改菜单文字，缺少窗口内状态 | 检查动画、禁用重复操作、上次成功检查时间、明确结果 |
| 下载没有可见进度 | `download-progress` 仅传给任务栏 | 窗口显示真实百分比/大小/速度/估算剩余时间，同时保留任务栏进度 |
| 下载、安装操作耦合 | `check()` 中连续请求下载和安装确认 | 分开检查、下载、取消、安装；下载后停留在准备就绪，安装仍需二次确认 |
| 关闭后立刻重开可能卡住 | Electron `close` 早于 `closed/isDestroyed`，复用了正在卸载的 renderer | 在 `close` 时解除复用和订阅，新窗口接续同一个控制器和下载 |
| 未知进度转为实际进度时短暂显得过高 | 等待条的固定宽度参与 CSS 宽度插值 | 首次实际进度直接显示真实宽度，后续测量才平滑过渡 |
| 刷新/授权/启动错误还是系统弹窗 | `main.cjs` 中各自调用系统 dialog | 复用本地确认窗口，默认焦点取消，关闭/Esc 按取消处理，不叠加多个确认 |
| 原生组件退出时突然打断用户 | native exit 回调直接弹警告框 | 可关闭的无声站内通知，保持语音和聊天；仍如实要求重启客户端以恢复原生组件 |
| 网页共享来源选择器风格旧、点击即开始 | 黑色内联样式，每张卡直接提交 | 复用粉色样式，屏幕/窗口分组、明确选中、单独确认、取消/空列表状态、键盘选择 |
| 缩放时设置窗口横向溢出 | 固定 body 最小宽度和内容默认最小尺寸 | 内容可收缩/换行，确认按钮可换行；标题栏保持可见 |
| 网页暂时无响应会拖住设置入口 | About 等待 renderer 版本探测没有上限 | 版本读取最多等 1 秒，失败不阻止访问设置 |

没有改 Piik、WebRTC、语音、频道、服务端或在线更新传输协议。沿用 electron-updater、NSIS、HTTPS、SHA512、禁止降级和手动安装策略。

## 安全和生命周期

- 设置页面为本地文件，启用 sandbox、contextIsolation，关闭 Node integration。主站网页没有新增更新/安装权限。
- 设置 IPC 同时核对自建窗口实例、主 frame 和准确的本地 URL；相同 URL 的非本组件窗口同样拒绝。
- CSP 禁止远程连接、外部脚本和 HTML 注入；版本、窗口名称及提示均按文本渲染。
- 下载由主进程持有，关闭设置只移除订阅，不中断下载/通话。进度未知时不显示伪造百分比。
- 取消使用 electron-updater 实际返回的 CancellationToken。校验失败不允许安装，取消后重新检查以取得新下载授权。
- 安装前再确认并调用既有原生清理；普通关闭客户端不会自动安装。
- 后台检查不弹窗、不下载、不重启。静态设置和确认窗口没有音频资源，显式静音。

## 用户验收

可双击 `desktop/windows/preview.vbs` 打开隔离的本地源码预览，再从“设置 → 关于与更新”看布局、颜色、拖动、关闭/Esc。开发预览诚实禁用下载安装；更新完整状态见本地测试截图。本轮不自动打开预览，不修改已有安装。

后续发布新版客户端后，实机验收：

1. 设置窗口位置合理、单实例；文字清晰，取消/Esc/关闭行为一致，没有操作提示音。
2. 实际点击检查：有等待动画，网络失败可重试，没有重复弹窗。
3. 有新版时下载：窗口内与任务栏显示真实进度；取消后停止传输；下载时关闭并重开窗口，仍看到同一次下载。
4. 在通话时下载/关闭设置，语音与共享不中断。下载完成不自动退出，选择“稍后安装”不结束通话。
5. 确认安装后再结束语音/共享并由安装程序继续；这一操作本轮未自动执行。
6. 分别检查 Windows 100/125/150/200% DPI、窗口缩放和减少动态效果设置；页面 zoom 自动化不能代替实际 Windows DPI。减少动态效果时按系统偏好停用动画，状态文字与实际进度仍可见。
7. 网页共享选择器先选择卡片，再确认；取消不开始共享；检查实际声音来源。

## 追加：托盘与关闭选择

新增 `window-lifecycle.cjs`、`window-preferences.cjs` 及自有耳机图标 `assets/tray.png`；在现有本地设置/确认 UI 内加入关闭选择和「窗口与托盘」设置，没有引入远程网页的退出/设置写入 IPC。

- 点 × 默认询问：最小化到托盘 / 退出客户端，并可记住。取消、Esc 和选择框 × 一律保持原窗口及原有设置。
- 托盘打开和重复启动均恢复同一个窗口，不重新启动原生组件；设置沿用现有入口；退出沿用 app.quit 和原生清理。隐藏窗口前关闭辅助窗口和来源选择器，避免遗留弹窗。
- 用户选择只保存于 userData/window-preferences.json；临时文件写入后原子替换。无效文件回退询问，写入失败不在内存里谎报已保存；托盘不可用时必须保持窗口可找回。
- 主页面禁用后台计时器节流，使隐藏到托盘后频道和媒体计时继续。未更改媒体路由、编解码、权限或服务端。
- 自动验证：459/459 单元测试；隐藏静音的真实 Electron 窗口关闭/本地 IPC、记住及跨实例读取、设置改回询问、取消/Esc、合成音轨保留、托盘销毁通过。测试使用替身托盘，不占用用户真实通知区；完整客户端 smoke 的原生 PID、刷新、合成媒体和退出清理通过。
- 截图与结果：`integrations/piik/artifacts/tray/close-choice.png`、`settings.png`、`result.json`。未生成新大型构建，未改客户端版本号，未提交、部署或更新本机安装。

人工验收：新版/隔离预览中分别选择两种关闭行为，勾选记住后重开验证；从设置改回每次询问；确认点击托盘恢复原频道、右键退出后原生进程释放。真实 Windows 通知区（可能被收进隐藏图标）、DPI、通话及共享长时间后台运行由用户验证。

## 仍然存在的系统边界

- Windows SmartScreen、系统隐私提示和 NSIS 安装阶段属于操作系统/安装程序。本轮不伪造它们的进度，也没有绕过安全提示。应用退出后的真实安装界面仍由 NSIS 管理。
- 安装前的应用内阶段显示等待动画，不把未知的安装完成度伪装成百分比。
- 还没有完整的离线重连页面。启动网络错误已有统一确认，但网络不可用时仍需恢复网络后重新打开客户端。
- 原生组件异常当前提示重启，尚未实现运行中无缝恢复；此次不改媒体生命周期。
- 此次不是整个平台所有页面的完整视觉验收。用户的真实 DPI、声音感受和安装升级体验仍需实机确认。
