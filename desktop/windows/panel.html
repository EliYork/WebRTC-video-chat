开源致谢

感谢以下项目的作者与贡献者，为语音据点提供基础能力与实现参考。点击项目名称可在默认浏览器中打开。

  • Piik · 原生共享与媒体传输
  • Pion WebRTC · 原生媒体连接基础
  • WebRTC-video-chat · 通话与共享参考
  • WebSocket-Cursor-Room · 共享鼠标参考
  • PeerJS · 实时音视频连接
  • mediasoup · SFU 转发
  • web-noise-suppressor · 浏览器降噪节点
  • RNNoise · 实时语音降噪
  • rnnoise-wasm · RNNoise 浏览器运行时
  • WorkAdventure noise-suppression · 增强降噪浏览器封装
  • DeepFilterNet · 增强降噪模型与核心
  • Electron · Windows 客户端运行框架

以上仅列出主要引用项目。各项目版权归原作者所有；完整许可请查阅项目仓库及随附的 LICENSE / THIRD-PARTY-NOTICES 文件。

网页刷新后生效；客户端和原生共享组件随客户端更新。

下载不会中断通话。安装前会再次确认，稍后安装不会在退出时自动执行。

关闭窗口后…

选择继续在后台运行，或结束通话并退出。

以后可在「设置 → 关于与更新 → 窗口与托盘」中修改。
