# EliYork Voice · Windows x64

下载对应版本的安装包（本次构建 **EliYork-Voice-Setup-0.1.5-x64.exe**）并双击，为当前用户安装（不需要管理员权限）。之后双击桌面 **EliYork Voice**。客户端打开独立窗口，默认连接 **https://voice.eliyork.com/room/lobby**，与普通浏览器共享频道、成员、聊天与语音。

不需要 Node、Go 或 PowerShell。旧 0.1.0 ZIP 需要先退出，再手动安装一次新版；旧目录可以保留。用户配置继续保存在 AppData。发布 ZIP 内包含安装包及更新元数据，不再是解压即用的便携目录。客户端内置 Electron/Chromium 与 Piik App/WGC 原生组件；网页无 Node 权限。麦克风/摄像头首次使用需授权，设备仍通过原频道界面选择。

## 原生共享

加入原语音频道 → 共享屏幕 → 默认原生共享 → 显示器/窗口 → 明确分辨率/FPS → 开始。组件会自动启动，无需打开 Piik 独立房间。首次驱动探测可能需等待数秒，再点刷新来源。来源声音按用户要求默认勾选；系统声音可能包含通话声音，可按需关闭。

选择“网页屏幕共享”时由客户端弹出画面选择窗口；勾选系统声音会捕获整个系统声音，而非单一窗口音频。取消不采集。真实麦克风、设备切换、系统声音和 4K60 体验仍需实机验收，自动化通过不代表画质/FPS 保证。

原生固定 H.264 硬件路径，自动选择首个可用硬件适配器；不保证一定选择 NVIDIA。当前不是原生 AV1。兼容观看者复用输出，不同网络需求可派生多个输出；每路最多三个直连观看者。P2P/STUN 对对称 NAT 或禁 UDP 网络没有全覆盖保证，TURN/SFU/多级转发未接入。

## 退出、诊断与更新

窗口顶部只显示一次“语音据点”；右侧为刷新及 Windows 原生最小化、最大化/还原、关闭按钮。刷新和 Ctrl+R/F5 仅重载频道页面；正在语音、共享或切换媒体时先确认，默认取消。确认刷新会结束当前通话/共享，需要重新加入；原生服务进程保持运行。

0.1.4 点击窗口 × 可选最小化到托盘或退出；关闭选择见下方「窗口与托盘」。右上角 **设置 → 退出** 仍会先结束媒体，再释放本次 App/采集进程。无需关闭日常浏览器。原生组件崩溃时语音聊天仍可用，重启客户端后重新开始原生共享；刷新/掉线后不自动恢复已结束采集。

F12 打开诊断工具。页面“复制诊断”提供摘要；原生日志位于 `%APPDATA%\EliYork Voice\native\logs\client.log`，客户端生命周期日志在同目录上级 `desktop.log`。日志可含故障/网络信息，分享前核对。不要分享 App 配置/本机 capability。

查看 NVIDIA 硬编：对应共享的 capture-state 应有 hardware=true、codec=h264、NVIDIA adapterName/encoderName，并与接收 video/H264、GPU Video Encode 负载对照；不能仅凭显卡存在或 H.264 文案确认。详细测试步骤见项目 `integrations/piik/ACCEPTANCE.md`。

## 在线更新（0.1.1 起）

已发布的 **0.1.1** 使用顶部 **EliYork Voice → 检查客户端更新**；还没有0.1.2 的新“设置”入口。**0.1.0 便携版没有在线更新**：先退出旧版，下载安装一次正式安装包，以后从安装版更新。不要删除 AppData 配置。0.1.2 发布后，0.1.1 安装版可通过现有菜单在线更新。Ctrl+R 只刷新网页。

0.1.2 使用右上角 **设置 → 关于与更新 → 检查更新**；关于窗口显示客户端版本、网页版本、连接地址及更新入口。设置菜单也保留直接检查更新、诊断与退出。启动 15 秒后及每 6 小时静默检查，只在菜单标记新版本。你选择“下载更新”后才下载，任务栏显示进度；完成后选择“退出并更新”或“稍后”。不会自动中断通话，不会在普通退出时偷偷安装；下次可再次通过菜单安装。安装前停止本次原生 App/采集进程。

## 新更新界面（0.1.4）

0.1.4 将系统消息框换成统一的粉色设置窗口。检查时显示加载动画；下载时显示真实百分比、大小、速度及估算剩余时间；支持取消、关闭后重开和失败重试。下载完成后由用户明确选择安装，并再次确认结束语音/共享。未知进度和安装准备使用等待动画，不伪造百分比。不会添加操作音效。

刷新确认、设备授权和启动错误同样采用本地无声确认窗口；原生组件退出改为可关闭的站内提示，不抢焦点。客户端的网页共享来源选择器统一为粉色卡片，先选中，再确认共享。已安装的 0.1.3 需要升级到 0.1.4 才能使用这些桌面界面。完整检查和验收见 `docs/DESKTOP-UI-POLISH-2026-10-19.md`。

## 源码 UI 的隔离预览

在此源码工作区双击 **desktop/windows/preview.vbs**。它使用本机已有 Node/Electron/Piik 构建，打开单独的客户端窗口，连接随机端口的 `127.0.0.1` 本地服务；不会连接线上频道、安装新版、改变原客户端配置或打开现有浏览器。没有命令行窗口。首次需要 Windows Script Host 可用；如果被系统策略禁止，可从项目根目录运行 `node scripts/preview-desktop.mjs`。

验收：确认顶部仅一个名称；拖动/缩放窗口，测试最大化、还原；检查刷新位于最小化左边；空闲刷新及加入语音后的刷新取消/确认；检查共享/无共享时左下 Dock、滚动频道列表、右侧聊天、下拉设备入口；检查 100%/125%/150%/200% Windows 显示缩放。缩放及原生窗口按钮需要实机确认，自动化页面 zoom 不代替系统 DPI 验收。结束预览时选择「退出客户端」或托盘右键退出，随后结束本次 Node、Go 和原生 App；最小化到托盘会继续运行预览服务。日志和独立配置在 `integrations/piik/.build/ui-preview/run-*`，最近一次路径见该目录 `latest.txt`。

此入口仅用于源码验收；日常使用请安装发布包，源码修改不会自动覆盖已安装客户端。

更新源固定为 `https://voice.eliyork.com/downloads/windows/`，使用 electron-updater 6.8.10 / NSIS，每用户安装、HTTPS 与 SHA512 完整性验证。当前没有代码签名证书，HTTPS 和摘要不能代替发布者签名；SmartScreen 仍可能提示。更新失败仍可使用旧版本。新版不强制降级；撤回坏版时先停止发布，再以更高版本号发布修复，或用户手动安装保留的旧版。

更新包约 150 MB，服务器会限制下载速度与并发，下载可能需要约 10 分钟；网络忙时可稍后重试。网站界面更新仍通过刷新获得；更新客户端用于 Electron/Piik/桌面权限等本机代码。卸载使用 Windows“已安装的应用”，默认保留 AppData 设置。

本构建未使用代码签名证书，Windows SmartScreen 可能显示未知发布者/拦截。核对提供方和 ZIP SHA256 后自行决定是否运行；不会自动绕过 SmartScreen。

## 窗口与托盘（0.1.4）

- 客户端运行时保留「语音据点」托盘图标；单击/双击可打开原窗口，右键提供打开、设置及退出入口。
- 首次点击主窗口 × 可选「最小化到托盘」或「退出客户端」，支持「记住我的选择」。取消、Esc 或关闭选择框不退出、不保存选择。
- 最小化到托盘仅隐藏窗口，语音、共享和原生组件继续运行；普通最小化按钮仍保留任务栏行为。托盘菜单的退出会结束语音和共享，并执行原有原生资源清理。
- 在「设置 → 关于与更新 → 窗口与托盘」中可改为每次询问、最小化到托盘或退出。保存于用户数据目录的 `window-preferences.json`，不改动 Piik 的配置。
- 托盘初始化失败时不会把窗口隐藏至无法找回的位置；系统关机、显式退出与更新安装不会被关闭询问拦住。不增加开机自启。
- 真实托盘、Windows DPI 与通话/共享中长期后台运行仍需实机验收；Windows 可能将托盘图标放在隐藏图标区。

## 频道提示音

成员加入播放柔和 do–re，离开播放 re–do；在 Dock 的声音下拉菜单中可关闭或调整提示音量，默认 35%，跟随总静音及输出设备。初始同步与本机断线恢复不补播；整个系统声音共享仍可能采集提示音。

## 故障恢复（0.1.5）

- 首次打开遇到断网或加载超时，可在本地无声窗口点击「重试连接」；复用原窗口，保留设置。选择退出或关闭确认框会退出客户端。已进入频道后的网络恢复仍由原有会话管理处理。
- 原生共享组件退出时，页面提供「恢复共享组件」；也可从设置菜单选择「恢复原生共享组件」。恢复保留网页、聊天与语音，组件正常时不会重复启动。恢复后请重新选择画面并开始共享，不会自动采集。
- 客户端 `desktop.log` 单文件 5 MiB，服务器 `logs/node.log` 单文件 10 MiB，各保留 3 份编号备份；单条写入最多 64 KiB。写盘失败退回 stderr，恢复可写后自动继续写盘。规则不修改 Piik 自身日志或 PM2 日志。
- 0.1.4 及更早安装版需要下载安装 0.1.5 才能获得本地故障恢复；更新仍需用户明确确认，不自动替换正在使用的客户端。验证范围见 `docs/DESKTOP-RECOVERY-2026-10-22.md`。
